Privacy Policy

DOM Router가 어떤 데이터를 읽고, 어디에 저장하며, 어떤 프로그램으로 전달하는지 설명합니다. 확장 기능과 별도 연동 프로그램의 처리 범위를 구분해 안내합니다.

선택한 웹페이지의 데이터를, 선택한 로컬 프로그램으로.

DOM Router는 사용자가 적용한 프로필에 따라 지정한 페이지 값을 읽고 같은 컴퓨터의 수신 프로그램에 JSON 이벤트로 전달하는 Chrome 확장 프로그램입니다. 광고·분석 서비스를 위한 원격 수집 기능은 포함하지 않습니다.

1. 목적과 적용 범위

이 방침은 DOM Router 확장 프로그램의 데이터 처리에 적용됩니다. 단일 목적은 사용자가 허용한 웹페이지와 로컬 프로그램 사이의 업무 데이터 연동입니다. 사용자가 사이트 접근 권한을 허용하고 프로필을 적용하면, 해당 프로필에서 지정한 DOM 값·페이지 콜백·요청 및 응답 필드를 관찰합니다.

사용자가 설정한 수신 프로그램, 해당 프로그램의 외부 서비스 연동, 방문하는 원래 웹사이트의 데이터 처리에는 각각의 운영자 방침도 적용됩니다.

2. 처리하는 데이터

구분내용과 용도
선택된 페이지 데이터프로필에 지정된 DOM 텍스트·속성·링크, 콜백 인자 및 요청·응답 필드. 문서번호, 수신점·대리점 코드와 명칭, 처리 결과 등이 포함될 수 있습니다. 선택한 값을 업무 이벤트로 구성합니다.
인증 관련 데이터프로필이 선택한 일회용 QR 인증 URL, 인증 거래 식별자, 만료 시각. URL에 인증에 필요한 토큰이 포함될 수 있습니다. 일반적인 계정 비밀번호나 인증 쿠키를 수집하도록 설계된 기능은 없습니다.
사이트·이벤트 정보이벤트가 발생한 사이트 origin(스킴·호스트·포트), 발생 시각, 임의 생성 설치 식별자, 탭·프레임·문서 세대 식별자와 프로필 버전. 이벤트의 출처를 구분하고 중복 처리·전달을 관리합니다. 전체 방문기록을 조회하는 기능은 없습니다.
설정과 연결 정보프로필, 허용할 사이트, DOM 선택자·필드 경로·조건, 로컬 수신부 주소와 식별 정보. 사용자가 토큰 인증 방식을 선택하면 입력한 수신부 인증 토큰도 저장합니다.
전달 대기·진단 정보대기 중인 JSON 이벤트, 처리 상태·재시도 횟수·오류 코드, 실행 로그 및 이벤트 매칭용 상태. 진단 로그에 문서번호·선택된 이벤트 payload·QR URL이 포함될 수 있습니다.

개인과 연결되는 문서·인증 식별자는 개인정보에 해당할 수 있습니다. 사용자 설정에 따라 선택되는 페이지 데이터가 달라지므로, 업무에 필요한 필드만 지정해 사용해야 합니다.

확장 프로그램은 로컬 신분증 이미지 파일을 직접 읽지 않습니다. 연동 DLL 등 별도 프로그램이 front.bmp 같은 이미지를 읽거나 복사하는 경우에는 해당 프로그램의 처리에 해당합니다.

3. 사용 목적과 제한

  • 프로필의 조건에 맞는 문서 등록·QR 준비 등 이벤트를 구성하고 지정한 로컬 프로그램에 제공합니다.
  • 연결 상태 표시, 출처 확인, 중복 처리 방지, 일시적 연결 실패 후 재전달 및 오류 진단에 사용합니다.
  • 데이터를 판매하거나 광고·신용평가·대출 심사 목적으로 사용하지 않습니다. 확장 기능과 무관한 분석 서버로 전송하는 기능은 포함하지 않습니다.

DOM Router의 사용자 데이터 사용 및 전달은 Chrome Web Store User Data Policy의 Limited Use 요구사항을 따릅니다. 데이터 사용·전달은 공개한 기능 제공에 필요한 범위로 제한하며, 개인화 광고에 사용하지 않습니다. 운영자가 사용자 데이터를 열람하는 것은 사용자의 특정 동의가 있는 지원, 보안 조사, 법적 의무 등 정책상 허용된 경우로 제한합니다.

4. 저장 위치와 전달 경로

설정·이벤트·로그·상태 정보는 사용자 Chrome 프로필의 IndexedDB와 chrome.storage.local에 저장합니다. 관찰 결과는 사용자가 설정한 127.0.0.1 수신부에 WebSocket(ws) 또는 HTTP로 전달합니다. 이 연결은 동일 컴퓨터 안의 통신이며, TLS 암호화를 사용하지 않는 방식입니다. 로컬 저장 데이터에 별도의 애플리케이션 암호화를 제공하지 않습니다.

확장 프로그램 자체에는 운영자 서버로 업무 이벤트를 직접 업로드하거나 원격 분석·광고 서비스로 보내는 기능이 없습니다. 그러나 로컬 프로그램에 전달한 뒤의 처리가 로컬에만 머문다는 뜻은 아닙니다.

DoriDori 연동 프로그램과 함께 사용하는 경우, 해당 프로그램은 전달받은 문서번호와 QR 링크를 스캔 이미지·업무 대상에 매핑한 후 DoriDori 서비스에 접수·제공할 수 있습니다. 외부 전달 항목과 수신자, 보관·삭제는 해당 연동 프로그램 및 서비스 운영자의 안내를 확인해야 합니다. 확장은 수신 프로그램이 이미 보관하거나 외부로 전송한 데이터를 회수·삭제할 수 없습니다.

5. 보관 기간과 삭제

  • 설정·매칭 상태: 프로필 버전·콜백 결합 상태·스냅샷·중복 식별 상태 등은 로컬 저장소에 남을 수 있습니다. 모든 데이터에 적용되는 일괄 자동 삭제 기간은 없습니다.
  • 전달 대기 이벤트: 전송 성공으로 처리된 이벤트는 대기 큐에서 삭제합니다. 설정한 대기 허용 시간을 넘으면 재전달을 차단하지만, 차단된 이벤트를 즉시 삭제하지는 않습니다. 일반 JSON WebSocket 모드의 전송 성공은 수신 프로그램의 영구 보관을 보장하지 않습니다.
  • 실행 로그: 최대 1,500건을 보관하고 새 로그가 추가될 때 오래된 항목을 정리합니다. 기간 기준 자동 삭제는 없습니다.
  • 프로필·연결 삭제: 프로필 삭제는 감지를 중단하지만 기존 버전·로그·대기 이벤트를 모두 삭제하지는 않습니다. 대기 이벤트가 있는 연결은 삭제가 제한될 수 있습니다.
  • 전체 로컬 데이터: Chrome 확장 관리에서 DOM Router를 제거하면 해당 Chrome 프로필에 저장된 확장 데이터가 삭제됩니다. 다시 설치할 경우 이전 설정을 재적용하기 전에 필요한 항목만 구성하세요.
  • 내보낸 파일·수신부 데이터: 사용자가 저장한 JSON 파일과 수신 프로그램·외부 서비스에 전달한 데이터는 별도로 삭제해야 합니다.

6. 사용자의 선택과 보호

프로필을 적용하기 전에 접근할 사이트, 읽을 필드와 전달할 수신부를 확인할 수 있습니다. 프로필 중지, 사이트 권한 취소, 확장 비활성화 또는 제거로 이후의 관찰을 제어할 수 있습니다. 프로필 중지만으로 이미 대기 중인 이벤트의 전송이 취소되지는 않습니다. 이후 전송까지 즉시 중단하려면 확장 프로그램을 비활성화하거나 제거하세요.

로컬 수신부는 사용자가 신뢰하는 프로그램만 실행해야 합니다. 키 없는 연결은 로컬 주소만으로 데이터를 전달할 수 있으므로 수신부 주소를 확인하세요. 로그·내보낸 JSON에 인증 URL이나 업무 정보가 포함될 수 있으므로 공개 저장소나 공개 문의에 원본을 올리지 마세요.

자동 실행 코드는 확장 패키지에 포함되어 있으며, 프로필은 미리 정의된 블록과 선택자·조건을 지정하는 JSON 설정입니다. 가져온 프로필에 포함된 JavaScript를 실행하는 기능은 없습니다.

7. 이 웹페이지와 방침 변경

이 페이지는 GitHub Pages로 제공되는 정적 문서입니다. 자체 분석 도구·광고·양식·외부 웹폰트·추적 스크립트를 포함하지 않습니다. 페이지 제공 과정에서 GitHub가 처리하는 접속 정보에는 GitHub 개인정보처리방침이 적용됩니다. 이 페이지를 여는 행위로 확장의 업무 데이터가 GitHub로 전송되지는 않습니다.

기능이나 처리 방식이 변경되면 이 페이지와 시행일을 갱신합니다. 이 문서는 DOM Router 1.4.3의 구현을 기준으로 작성되었습니다.

DOM Router Privacy Policy

Effective October 21, 2026 · Reviewed against version 1.4.3

1. Purpose and scope

DOM Router is a Chrome extension for browser-to-local workflow data integration. After you grant site access and apply a profile, it observes the DOM values, page callbacks, and request/response fields specified by that profile, and sends selected JSON events to a program you configure on the same computer. This policy covers the extension. Websites, local receiving programs, and downstream services also have their own data practices.

2. Information handled

  • Selected website content: DOM text, attributes and links, callback arguments, and selected request/response fields. Business profiles can include document identifiers, recipient and agency codes/names, and operation results.
  • Authentication information: one-time QR verification URLs, transaction identifiers and expiry times. QR URLs may contain authentication tokens. The extension is not designed to collect general account passwords or authentication cookies.
  • Event and source metadata: source origin (scheme, host and port), event time, a randomly generated installation identifier, tab/frame/document-generation identifiers, and profile versions. These support event attribution, deduplication and delivery. The extension does not read your complete browsing history.
  • Configuration and connection information: profiles, site origins, selectors, field paths, conditions, local receiver addresses and receiver identity. An optional token-authenticated connection also stores the receiver token you provide.
  • Local workflow records: queued events, matching state, delivery status, retry counts, error codes and diagnostic logs. Logs can include document identifiers, selected event payloads and QR URLs.

Document or authentication identifiers linked to a person may be personal information. The fields handled depend on the profile; select only fields needed for your workflow. The extension does not directly read local identity-card image files. Reading or copying files such as front.bmp is a function of a separate local program, if installed.

3. Use and Limited Use

Data is used to produce configured workflow events, deliver them to your local receiver, show connection status, manage event identity, retry delivery and diagnose errors. DOM Router does not sell data or use it for advertising, creditworthiness or lending. It includes no upload function for unrelated operator analytics or advertising servers.

DOM Router's use and transfer of user data adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Use and transfer are limited to the disclosed functionality and are not used for personalized advertising. Operator access to user data is limited to permitted cases such as specific user consent for support, security investigations, and legal obligations.

4. Storage, transmission and downstream programs

Settings, events, logs and workflow state are stored in IndexedDB and chrome.storage.local within your Chrome profile. Events are sent to a user-configured 127.0.0.1 receiver through local WebSocket (ws) or HTTP. This is same-computer communication without TLS. The extension does not provide separate application-level encryption of its local storage.

The extension itself does not upload business events directly to an operator's remote server or to remote analytics or advertising services. This does not mean a receiving program keeps all data local. When used with a DoriDori integration program, that program can associate the document identifier and QR URL with a scanned image and workflow target, and submit them to DoriDori. Review the receiving program's and service operator's disclosures for recipients, retention and deletion. The extension cannot recall or delete data already retained or forwarded by those programs.

5. Retention and deletion

  • Settings, profile revisions, callback-joining records, snapshots and deduplication records may remain locally. There is no universal time-based purge of all extension data.
  • Events treated as successfully sent are removed from the outbox. Events exceeding the configured delivery age become blocked; this does not immediately delete them. A successful send in generic JSON WebSocket mode does not guarantee durable storage by the receiver.
  • Logs are limited to the latest 1,500 records and older records are removed as new logs are added. There is no time-based log expiration.
  • Deleting a profile stops observation but does not erase all previous revisions, logs or queued events. Connection deletion may be restricted while queued events remain.
  • Uninstall DOM Router through Chrome's extension manager to remove its stored data for that Chrome profile. Downloaded JSON exports and data retained by local or external receiving services must be deleted separately.

6. Your choices and safeguards

Review the target sites, selected fields and receiver before applying a profile. You can stop a profile, revoke site access, disable the extension or uninstall it. Stopping a profile does not cancel already queued deliveries. Disable or uninstall the extension to immediately stop further extension processing and delivery.

Run only a trusted local receiver and verify its address, especially for keyless connections. Diagnostic files can contain sensitive QR links or business data; do not post unredacted records in a public repository or issue. Executable scripts are bundled with the extension; imported JSON profiles select predefined blocks and configuration values and cannot supply executable JavaScript.

7. This website and policy updates

This is a static GitHub Pages document without custom analytics, advertising, forms, external webfonts or tracking scripts. GitHub's handling of website connection data is covered by the GitHub Privacy Statement. Opening this page does not upload extension workflow data to GitHub. This page and its effective date will be updated when the described data practices change.
