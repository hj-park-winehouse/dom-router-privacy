개인정보처리방침

선택한 웹페이지의 데이터를, 선택한 로컬 프로그램으로.

시행일: 2026년 10월 21일

1. 처리하는 정보와 목적

DOM Router는 사용자가 허용한 웹페이지에서 프로필로 지정한 DOM 값, 페이지 콜백, 요청·응답 필드를 읽어 로컬 프로그램에 전달하는 확장 프로그램입니다.

선택한 텍스트·링크·항목 식별자·처리 결과와 이벤트 출처·시각, 설정·연결 정보, 실행 로그·전달 대기 데이터를 처리합니다. 프로필에 따라 개인정보나 일회용 인증 링크·토큰이 포함될 수 있으며, 토큰 인증 연결을 선택하면 입력한 수신부 토큰도 저장합니다.

이 정보는 설정한 데이터 연동, 연결 상태 확인, 전달 재시도와 오류 진단에만 사용합니다.

2. 저장과 전달

설정과 처리 기록은 사용자 브라우저에 저장합니다. 선택된 데이터는 사용자가 지정한 같은 컴퓨터의 수신부(127.0.0.1)에 WS 또는 HTTP로 전달합니다. 개발자의 원격 서버로 데이터를 보내거나 광고·분석 서비스를 위해 수집하는 기능은 없습니다.

수신 프로그램은 전달받은 데이터를 다른 자료와 결합하거나 외부 서비스로 전달할 수 있습니다. 이후의 처리와 삭제에는 해당 프로그램·서비스의 방침이 적용됩니다.

3. 보관과 삭제

전송 성공으로 처리된 이벤트는 대기 목록에서 삭제합니다. 실행 로그는 최대 1,500건까지 보관하며, 오래된 기록부터 정리합니다. 설정·일부 처리 기록·실패 이벤트는 별도의 기간 제한 없이 남을 수 있습니다.

프로필을 중지·삭제해도 기존 로그와 대기 데이터가 모두 삭제되지는 않습니다. 확장 프로그램을 제거하면 해당 브라우저 프로필의 확장 데이터가 삭제됩니다. 내보낸 파일과 수신 프로그램에 전달된 데이터는 별도로 삭제해야 합니다.

4. 사용자 선택과 이용 제한

사용자는 적용할 프로필·접근할 사이트·전달할 수신부를 선택할 수 있습니다. 프로필 중지나 사이트 권한 취소로 이후 관찰을 제어할 수 있으며, 대기 중인 전달까지 중단하려면 확장을 비활성화하거나 제거하세요.

사용자 데이터를 판매하거나 개인화 광고·신용평가·대출 심사에 사용하지 않습니다. 데이터 사용·전달은 Chrome Web Store User Data Policy의 Limited Use 요구사항에 따라 공개한 기능 제공에 필요한 범위로 제한합니다.

Privacy Policy

Selected page data, routed to your chosen local program.

Effective October 21, 2026

1. Information and purpose

DOM Router reads profile-selected DOM values, page callbacks and request/response fields on sites you authorize, and routes selected data to a local program.

It handles selected text, links, item identifiers and results; event origins and times; settings and connection information; logs and queued events. Profiles may select personal information or one-time authentication links/tokens. Token-authenticated connections also store the receiver token you provide.

Data is used only for your configured integration, connection status, delivery retries and troubleshooting.

2. Storage and transmission

Settings and records are stored in your browser. Selected data is delivered through WS or HTTP to your chosen receiver on the same computer (127.0.0.1). The extension includes no function that sends data to the developer's remote server or collects it for advertising or analytics.

Your receiving program may combine data with other records or forward it to an external service. Subsequent processing and deletion are covered by that program's and service's policies.

3. Retention and deletion

Events treated as successfully sent are removed from the queue. Logs are limited to the latest 1,500 records. Settings, some processing records and failed events may remain without time-based expiration.

Stopping or deleting a profile does not erase all logs or queued data. Uninstalling removes extension data from that browser profile. Exported files and data already delivered to receiving programs must be deleted separately.

4. Your choices and Limited Use

You choose profiles, site access and receivers. Stop profiles or revoke site permissions to control further observation. Disable or uninstall the extension to also stop queued delivery.

Data is not sold or used for personalized advertising, creditworthiness or lending. Use and transfer are limited to the disclosed functionality in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

5. Contact and changes

Privacy inquiries: wine.mvno.01@gmail.com. Inquiry information is used for replies and support. Exclude personal information, authentication tokens and private links.

Changes are published here with an updated effective date. This page uses GitHub Pages without custom tracking tools. Website connection information is covered by GitHub's policy.
